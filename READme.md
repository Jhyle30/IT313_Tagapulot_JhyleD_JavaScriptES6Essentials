# IT313 JavaScript ES6 Essentials

## Problem

This program checks the eligibility of students based on their
prelim, midterm, and final grades.

A student is PASSING if the average is 75 or above.
Otherwise, the student is on PROBATION.

## Approach

I used const and let, arrow functions, template literals,
destructuring, map(), filter(), reduce(), import and export,
Promises, async/await, and try/catch.

The gradeUtils.js file contains the grade functions.

The main.js file processes the enrollee records and displays
the eligibility report.

## How to Run

Run this command:

node main.js
